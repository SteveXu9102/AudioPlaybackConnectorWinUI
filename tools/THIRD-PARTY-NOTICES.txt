This file is the single description of those components, and it is the file that
is edited. tools/assemble-third-party-notices.ps1 assembles the complete text at
build time: it takes this file as it stands and appends the licence and notice
text of every redistributed NuGet package, read from the restored packages rather
than transcribed by hand. The assembled text is written to the repository root as
THIRD-PARTY-NOTICES.txt before the application is compiled, so the resource
script embeds that complete text in the executable (RCDATA 301, stored compressed
and decompressed in memory when the dialog opens, which reads no file), and
tools/package-single-file.ps1 copies the same bytes next to every packaged file.
The text those copies carry and the text the program shows are therefore one
document, and the notice text cannot drift from what is distributed.

The links below are a convenience for a reader who wants a component's terms from
where they are published. Each was checked with an HTTP request on 2026-09-24,
and the status then observed is written next to it. A link is not a notice and
does not discharge the obligation: the terms themselves travel in this file, and
the complete text is what is compiled into the program and shipped beside it.

The application shows the complete text and LICENSE.txt in its Licenses dialog -
right click the notification-area icon - so the notices can be read without
leaving the program.
